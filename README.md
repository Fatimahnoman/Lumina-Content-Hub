# ⚡ LUMINA — Ultra-Fast Dynamic Content Engine & Learning Hub

> A high-performance, SEO-optimized tech publication platform designed for sub-second content rendering, dynamic category filtering, and an elevated reading experience.

---

## 🌟 Overview

**LUMINA** is a modern content engine and dynamic learning hub engineered for tech publications, media platforms, and engineering blogs. Built with a focus on lighting-fast dynamic rendering, modern dark-mode glassmorphism, and crisp typography, it offers advanced reader utilities including reading time progress tracking, instant client-side search, multi-tag filtering, and local bookmarking capabilities.

## ✨ Key Features

* 💎 **Minimalist Obsidian UI:** Deep dark-mode theme (#090D16) with vibrant purple/indigo glow gradients and frosted glass reader cards.
* ⚡ **Lightning-Fast Search & Filtering:** Instant debounced search bar alongside category multi-tag selectors (`AI & ML`, `Full-Stack`, `Architecture`, `UI/UX Design`).
* 📖 **Enhanced Reader Experience:**
  * Fixed reading time progress indicator at the top of the viewport.
  * Interactive Table of Contents (TOC) with active section tracking.
  * Local storage bookmarking/favorite toggle.
  * Custom font-size adjustment controls for accessible reading.
* 👨‍💻 **Rich Media & Author Attribution:** Author profiles, reading time badges, dynamic tags, and related article recommendation carousels.

## 🛠️ Tech Stack

* **Frontend Framework:** React / Next.js, TypeScript
* **Styling & Design:** Tailwind CSS, Glassmorphism, Modern Typography
* **State & Content Management:** MDX / Dynamic Local Content Architecture
* **Icons & UI Polish:** Lucide React, Framer Motion
* **Deployment:** Vercel / Bolt

## 🚀 Getting Started (Local Setup)

To run this project locally on your machine:

```bash
# 1. Clone the repository
git clone [https://github.com/Fatimahnoman/lumina-content-hub.git](https://github.com/Fatimahnoman/lumina-content-hub.git)

# 2. Navigate into the project directory
cd lumina-content-hub

# 3. Install required dependencies
npm install

# 4. Start the local development server
npm run dev
